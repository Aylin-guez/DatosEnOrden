# Politica de confianza

Esta politica define como DatosEnOrden mantiene confianza publica cuando cita evidencia, enfrenta informacion incompleta o comunica incertidumbre.

## Como se cita evidencia

Cada afirmacion publicada debe quedar conectada con evidencia verificable.

Una cita de evidencia debe incluir, cuando exista:

- nombre de la fuente oficial;
- titulo o tipo del documento fuente;
- identificador oficial;
- fecha de publicacion, emision, actualizacion u observacion;
- URL oficial o ruta de consulta;
- fragmento, campo, pagina, seccion o registro que sostiene la afirmacion;
- fecha en que DEO observo o proceso la fuente.

La evidencia debe estar cerca de la explicacion. Una persona no deberia tener que navegar por varias capas para saber de donde sale una afirmacion central.

## Cuando no hay evidencia suficiente

Si no hay evidencia suficiente, DEO debe reducir o detener la afirmacion.

Opciones permitidas:

- no publicar la afirmacion;
- publicar solo el hecho verificable minimo;
- marcar la informacion como limitada;
- explicar que falta para confirmar;
- mantener el elemento como pendiente de revision;
- vincular solo la fuente disponible sin agregar conclusiones.

DEO no debe completar vacios con inferencias, suposiciones o lenguaje que sugiera certeza.

## Cuando una fuente oficial contradice otra

Si dos fuentes oficiales se contradicen, DEO debe tratar la contradiccion como un hecho documental que requiere trazabilidad.

Debe:

- citar ambas fuentes;
- indicar que existe una diferencia entre fuentes;
- evitar decidir cual es verdadera si no hay una regla documental clara;
- registrar fechas, versiones e instituciones responsables;
- explicar el alcance de la contradiccion;
- actualizar el tema si una fuente posterior resuelve la diferencia.

La contradiccion no autoriza a DEO a opinar. Autoriza a mostrar evidencia, contexto y limitaciones.

## Como marcar limitaciones

Las limitaciones deben aparecer donde afecten la lectura ciudadana.

Ejemplos de limitaciones:

- la fuente no entrega fecha de actualizacion;
- el documento no incluye anexos;
- el identificador existe, pero no hay texto completo disponible;
- la fuente fue observada en una fecha especifica y pudo cambiar despues;
- el dato viene de una muestra o carga parcial;
- dos fuentes oficiales usan criterios distintos;
- el documento tiene estado preliminar, historico, reemplazado o rectificado.

Una limitacion no debe esconderse en notas tecnicas si cambia el sentido de la lectura principal.

## Como evitar conclusiones falsas

DEO evita conclusiones falsas aplicando estas reglas:

- no convertir correlacion temporal en causalidad;
- no inferir intencion de una autoridad, institucion o persona;
- no usar lenguaje como sospecha, irregularidad, conflicto o riesgo si la fuente no lo establece;
- no mezclar eventos de temas distintos sin evidencia de relacion;
- no presentar datos incompletos como panorama total;
- no usar resumenes como sustituto del documento fuente;
- no simplificar una contradiccion oficial hasta hacerla desaparecer.

La claridad ciudadana no puede construirse a costa de precision documental.

## Como comunicar incertidumbre

La incertidumbre debe comunicarse de forma directa, breve y verificable.

Formulas aceptables:

- "La fuente disponible no permite confirmar..."
- "No se encontro evidencia oficial suficiente para..."
- "La informacion revisada llega hasta..."
- "Existen diferencias entre fuentes oficiales..."
- "El documento no especifica..."
- "DEO observo esta fuente el..."

La incertidumbre debe explicar que se sabe, que no se sabe y que evidencia seria necesaria para mejorar la lectura.

## Regla final

Cuando exista tension entre claridad, velocidad y verificabilidad, DEO elige verificabilidad.

La confianza no depende de parecer completo. Depende de mostrar que se sabe, que falta y donde esta la evidencia.
