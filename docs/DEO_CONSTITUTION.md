# Constitucion DEO v1

DatosEnOrden es una memoria viva del Estado basada en documentos oficiales.

Este documento define la identidad permanente del proyecto. Su funcion es orientar decisiones de producto, datos, documentacion y publicacion cuando aparezcan nuevas fuentes, nuevas interfaces o nuevas formas de explicar informacion publica.

## 1. Que es DatosEnOrden

DatosEnOrden es una infraestructura publica para ordenar, preservar y explicar informacion oficial del Estado de forma verificable.

No parte desde opiniones, tendencias ni relatos externos. Parte desde documentos, registros y fuentes oficiales. Su trabajo es convertir esas fuentes en memoria comprensible: eventos, temas, cronologias, evidencia y lecturas documentadas que permitan a cualquier ciudadano entender que cambio, de donde viene y como verificarlo.

DEO no reemplaza al Estado ni a sus portales. Tampoco reemplaza a los documentos oficiales. Organiza la relacion entre documentos, eventos y temas para que la informacion publica no quede perdida, fragmentada o aislada.

## 2. Que problema resuelve

La informacion oficial suele estar dispersa entre portales, boletines, documentos PDF, registros administrativos, bases de datos y paginas institucionales. Cada fuente puede ser correcta dentro de su propio contexto, pero el ciudadano queda obligado a reconstruir la historia por su cuenta.

DatosEnOrden resuelve ese problema creando continuidad documental:

- conecta fuentes oficiales con eventos verificables;
- agrupa eventos dentro de temas persistentes;
- conserva cronologias para entender cambios en el tiempo;
- mantiene la evidencia cerca de cada explicacion;
- separa el documento original de cualquier lectura resumida;
- preserva historial cuando una fuente cambia.

El objetivo no es producir una conclusion, sino permitir una lectura verificable.

## 3. Principios no transables

- Todo debe poder verificarse.
- El documento fuente tiene prioridad.
- La explicacion nunca reemplaza al documento.
- Un cambio oficial produce un evento.
- Los eventos construyen la historia de un tema.
- Los temas no mueren; se actualizan.
- DEO observa, no opina.
- La evidencia debe estar mas cerca que la explicacion.
- El ciudadano nunca debe perderse.
- Si una fuente cambia, DEO debe preservar historial.
- Si DEO se equivoca, debe corregir de forma visible.

Estos principios tienen prioridad sobre cualquier optimizacion tecnica, decision editorial o mejora visual.

## 4. Que nunca hara DEO

DatosEnOrden nunca debe:

- publicar afirmaciones sin evidencia suficiente;
- presentar una interpretacion como si fuera un hecho oficial;
- ocultar la fuente primaria detras de una explicacion;
- borrar historial relevante cuando una fuente cambia;
- convertir incertidumbre en certeza;
- usar lenguaje acusatorio, partidista o inferencial;
- producir rankings, puntajes o juicios de valor sobre actores publicos;
- reemplazar el documento oficial por un resumen propio;
- publicar automaticamente contenido que no haya pasado reglas de trazabilidad;
- mezclar opinion, noticia o analisis editorial con evidencia documental.

DEO puede explicar, ordenar y contextualizar. No debe opinar, concluir por el ciudadano ni insinuar causalidades que no esten documentadas.

## 5. Como trata fuentes oficiales

Una fuente oficial es un origen institucional verificable: un portal publico, registro administrativo, documento oficial, boletin, ley, decreto, resolucion, informe, votacion, acta, contrato, expediente u otro soporte publicado por una entidad competente.

DEO trata cada fuente oficial con estas reglas:

- conserva identificadores, fechas, URLs y metadatos cuando existan;
- distingue entre la fuente institucional y el documento especifico;
- registra cambios detectables como eventos;
- no asume que dos fuentes dicen lo mismo aunque parezcan relacionadas;
- no corrige silenciosamente a una fuente oficial;
- preserva versiones, fechas de observacion o historial disponible cuando la fuente cambia;
- marca limitaciones cuando la fuente no entrega suficiente contexto.

La fuente oficial no es decoracion ni bibliografia secundaria. Es la base de la memoria.

## 6. Que significa evidencia

Evidencia es el respaldo verificable que permite revisar una afirmacion de DEO.

Puede ser:

- un documento fuente;
- un identificador oficial;
- una URL oficial;
- una fecha de publicacion o actualizacion;
- un fragmento citado o referencia interna de un documento;
- una fila, registro o campo proveniente de una fuente oficial;
- una relacion trazable entre evento, documento y tema.

La evidencia debe permitir responder: quien lo publico, donde esta, cuando fue observado, que dice y como se conecta con la afirmacion.

Una explicacion sin evidencia cercana no cumple el estandar de DEO.

## 7. Cuando una afirmacion puede publicarse

Una afirmacion puede publicarse solo si:

- tiene una fuente oficial identificable;
- la evidencia esta disponible o referenciada de forma clara;
- el texto distingue hechos documentados de contexto explicativo;
- no agrega causalidad, intencion o juicio que la fuente no sostenga;
- indica limitaciones relevantes cuando existan;
- permite que una persona llegue al documento o registro de origen;
- puede corregirse si la fuente cambia o si DEO detecta un error.

Si la evidencia es incompleta, la afirmacion debe reducirse, marcarse como limitada o no publicarse.

## 8. Como se corrigen errores

Si DEO se equivoca, debe corregir de forma visible.

Una correccion debe:

- indicar que hubo una correccion;
- describir que cambio sin ocultar la version anterior cuando sea relevante;
- preservar la trazabilidad hacia la fuente correcta;
- registrar fecha de correccion cuando el soporte lo permita;
- evitar culpar a la fuente si el error fue de procesamiento, lectura o presentacion de DEO.

Corregir no es solo editar texto. Es mantener confianza mediante historial, claridad y evidencia.

## 9. Como se manejan cambios en fuentes oficiales

Una fuente oficial puede cambiar: publicar una nueva version, actualizar un estado, retirar un documento, corregir un dato, agregar anexos o modificar una pagina.

Para DEO, un cambio oficial produce un evento.

Cuando se detecta un cambio, DEO debe:

- registrar el cambio como evento cuando sea relevante;
- asociarlo al tema correspondiente;
- preservar historial disponible;
- distinguir entre cambio de fuente y cambio de interpretacion de DEO;
- actualizar la cronologia del tema;
- mantener acceso a la evidencia anterior cuando sea posible;
- explicar el estado actual sin borrar la historia documentada.

El cambio no reemplaza automaticamente la historia. La actualiza.

## 10. Como se mantiene neutralidad

DEO mantiene neutralidad mediante disciplina documental:

- usa lenguaje descriptivo, no acusatorio;
- separa hechos oficiales de explicaciones;
- evita intenciones, motivaciones y causalidades no documentadas;
- no asigna culpa, merito, riesgo ni importancia politica por inferencia;
- muestra evidencia antes que interpretacion;
- conserva limitaciones visibles;
- trata fuentes oficiales contradictorias como una condicion documental, no como una conclusion.

Neutralidad no significa ausencia de estructura. Significa que la estructura ayuda a verificar, no a persuadir.

## 11. Diferencia con noticias, opinion, dashboards y portales publicos

DEO no es un medio de noticias. No compite por primicias, titulares ni cobertura editorial. Su unidad principal no es la noticia, sino el evento documentado dentro de la historia de un tema.

DEO no es opinion. No busca convencer ni evaluar. Observa, ordena y presenta evidencia.

DEO no es solo un dashboard. Un dashboard muestra indicadores; DEO conserva memoria documental, cronologia y evidencia verificable.

DEO no es un portal publico oficial. Los portales oficiales publican documentos y registros desde cada institucion. DEO organiza esas fuentes para que el ciudadano pueda seguir temas, cambios y relaciones sin perder el documento de origen.

## 12. Relacion entre conceptos centrales

### Fuente oficial

Origen institucional verificable. Es el lugar desde donde DEO observa documentos, registros o cambios.

### Documento fuente

Unidad documental especifica publicada o mantenida por una fuente oficial. Tiene prioridad sobre cualquier resumen de DEO.

### Evidencia

Referencia verificable que conecta una afirmacion con su documento, registro o fuente oficial.

### Evento

Cambio observado desde una fuente oficial. Puede ser una publicacion, actualizacion, votacion, informe, decreto, nuevo documento, cambio de estado u otro hecho documentado.

### Tema

Asunto publico persistente que acumula eventos, documentos y evidencia. Un tema no muere: se actualiza cuando hay nuevos eventos.

### Cronologia

Secuencia de eventos asociados a un tema. Permite entender como evoluciona la historia documentada.

### Lectura documentada

Explicacion ciudadana basada en evidencia cercana. Ayuda a entender, pero nunca reemplaza al documento fuente.

### Pulso del Estado

Vista agregada de cambios recientes observados desde fuentes oficiales. No es opinion ni tendencia editorial; es una forma de mostrar que se movio en el Estado y que evidencia lo respalda.

## Modelo de relacion

```text
Fuente oficial
  -> Documento fuente
    -> Evidencia
      -> Evento
        -> Tema
          -> Cronologia
            -> Lectura documentada
              -> Pulso del Estado
```

La lectura documentada existe para que el ciudadano comprenda. La evidencia existe para que pueda verificar. La fuente oficial existe para que DEO no invente memoria.
