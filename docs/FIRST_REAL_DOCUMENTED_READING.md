# First Real Documented Reading

## Objetivo

Publicar la primera Lectura Documentada real usando un documento oficial pequeno, verificable y trazable. El objetivo no es cubrir todo el ecosistema, sino demostrar el flujo completo con bajo riesgo editorial y tecnico.

## Flujo manual inicial

1. Elegir documento oficial.
2. Guardar metadata: titulo, organismo, fecha, URL oficial, tipo documental y estado.
3. Extraer texto de forma controlada, registrando origen y fecha de consulta.
4. Dividir en paginas, secciones y fragmentos.
5. Crear anclas estables por fragmento.
6. Crear resumen ciudadano neutral.
7. Crear preguntas ciudadanas.
8. Crear referencias con pagina, seccion, fragmento y cita breve.
9. Publicar como Actualidad Documentada.
10. Enlazar a expediente, reporte o seguimiento si aplica.

## Candidatos de fuente

- Biblioteca del Congreso Nacional
- Diario Oficial
- Ministerio correspondiente
- DIPRES
- ChileCompra si es una compra o licitacion
- Contraloria

## Criterio para el primer documento

El primer documento debe ser pequeno y verificable. Debe tener una fuente oficial clara, texto estable, fecha identificable y contenido que pueda revisarse manualmente. Evitar documentos extensos, ambiguos o politicamente cargados hasta validar el flujo editorial.

## Separacion demo / real

Los datos demo siguen marcados como `LOCAL_TEST_DATA` y `NOT_OFFICIAL_DATA`. El primer documento real debe guardarse de forma separada, sin subir datos sensibles ni material que no deba publicarse. Cualquier import real debe pasar por revision antes de versionarse.
