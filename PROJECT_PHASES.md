# Project Phases

## Fase 1 - Ecosistema / Plataforma base

**Estado:** completada conceptualmente.

Esta fase deja construida la base de plataforma necesaria para comprender, conectar y publicar informacion documentada sin depender de una sola pantalla o flujo manual.

Incluye:

- Platform Core
- Entity Resolution
- Dataset Registry
- Data Pipeline
- Reading Pipeline
- Knowledge Engine
- Publication Engine
- Actualidad Documentada
- Biblioteca
- Expedientes
- Seguimiento
- Reportes
- Documento Oficial / Lectura Documentada

## Fase 2 - Primeras fuentes y documentos reales

**Estado:** actual.

Objetivo: publicar la primera Lectura Documentada real, usando un documento oficial pequeno, verificable y trazable. La prioridad es mantener separacion clara entre demo local y contenido publico real.

## Fase 3 - Dominio publico

**Objetivo:** preparar `datosenorden.cl` como superficie publica estable para lecturas documentadas, expedientes, seguimiento y verificacion ciudadana.

## Fase 4 - Comunidad / feedback

**Objetivo:** incorporar retroalimentacion ciudadana y editorial sobre claridad, trazabilidad, lectura publica y utilidad civica.

## Fase 5 - DatosEnOrden Studio comercial

**Objetivo:** separar capacidades reutilizables de Studio para clientes, organizaciones y productos derivados, manteniendo el sitio publico como cliente de esos motores.
